🤖 AI Text Summarizer

An AI-powered Text Summarization Web Application built using FastAPI, Hugging Face Transformers, PyTorch, and T5.

The application accepts long text or conversations from the user and generates a concise summary using a fine-tuned T5 Transformer model.

🚀 Features
📝 Summarize long text and conversations
🤖 Fine-tuned T5 Transformer model
⚡ FastAPI backend for model inference
🌐 Interactive web-based UI
📋 Copy generated summary with one click
🔢 Input and output character counter
⏳ Loading indicator during summarization
💻 Supports CPU, NVIDIA CUDA, and Apple Silicon MPS
🔌 REST API endpoint for programmatic summarization
